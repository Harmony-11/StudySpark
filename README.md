# StudySpark 📚✨

**Study smarter. Grow stronger. Spark your potential.**

StudySpark is an interactive study platform for students, bringing SAT practice, quizzes, flashcards, notes, study planning, progress tracking, and a customizable study companion into one place.

## Features
- SAT-style Reading and Writing and Math practice
- Quizzes, flashcards, and study notes
- Study planner and progress tracking
- A dark, violet study-space interface
- Spark companion preferences for a more personal study experience
- A student community concept, with group chat planned for a future backend-connected version

## Run locally
Open `index.html` in a modern browser. No build step is required for the static demo.

## Important notes
- This is an independent learning project, not an official College Board product. Practice questions and score estimates are not official SAT content or scores.
- The static demo does not provide secure user accounts or live cross-user chat. Those features require a backend service with authentication, database security rules, and moderation tools.
- Do not put passwords, service-role keys, or private student information in this public repository.
- For student safety, display names should be public; email addresses, exact birth dates, and student IDs should remain private and should only be collected when truly necessary.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save. Once GitHub finishes deployment, it will show the public site URL in the Pages settings.

## Project status
StudySpark is a work in progress. Features and content may change as the project develops.
