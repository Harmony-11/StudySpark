# VYBORA ✦
**Your world. On repeat.** A responsive social-platform prototype combining ideas from video sharing, music streaming, short-form creator videos, photo feeds, stories, and messaging.

## Preview
Open [index.html](./index.html) in a browser, or deploy this folder as a static site.

## Prototype features
- Responsive violet/dark interface with desktop sidebar and mobile navigation
- Feed filters for videos, music, dance, style, and art
- Search across sample posts
- Interactive likes and follow buttons
- Story circles, creator spotlight, trending list
- Music-player UI with track switching and playback-state controls
- Share/save/comment interactions with prototype feedback

## Important
This is a **front-end prototype**, not yet a production social network. The feed uses sample data; music playback is a UI preview and no copyrighted tracks are bundled. Accounts, real uploads, hosted video/audio, persistent likes, direct messages, moderation, and multi-user synchronization require a backend and appropriate storage/authentication services.

## Run locally
Open `index.html` directly in a modern browser. No build tools are required.

## Publish
To make this publicly accessible, deploy the `vybora` folder using a static hosting provider, or move the contents of this folder to the repository root and enable GitHub Pages in the repository's Settings → Pages. Do not publish private credentials or API keys in front-end files.
